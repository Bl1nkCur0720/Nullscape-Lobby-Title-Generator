本目录下的字体文件均为第三方作品，版权归各自作者/发行方所有，
本项目不拥有、不重新授权这些字体。

- 完整授权说明、字体来源清单与许可证全文：仓库根目录的 `FONT-LICENSES.md`
- 本项目代码本身的许可：仓库根目录的 `LICENSE`（MIT，不涵盖本目录）

这些字体仅用于网页端预览 Roblox Rich Text 的显示效果；生成的代码只引用
Roblox 官方字体族路径（rbxasset://fonts/families/*.json），不嵌入字体数据。
